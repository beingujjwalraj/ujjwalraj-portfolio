## ⚡ Quick Start / Local Development

Clone the repository and install dependencies:

```bash
# Clone the repository
git clone https://github.com/beingujjwalraj/ujjwalraj-portfolio.git

# Navigate into directory
cd ujjwalraj-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` (or `http://localhost:5173`) in your browser.

---

## 🏗️ Production Build

Generate optimized production bundle:

```bash
npm run build
```

The compiled static assets will be output to the `dist/` directory, ready to deploy to Netlify, Vercel, or any CDN.
